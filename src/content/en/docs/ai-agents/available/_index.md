The **Available** tab lists agents you can install for your organization. Each card shows the agent name, category, description, included skills, where it works, and what it is based on.

## How to access

1. Open **Agents** in the left sidebar
2. Select the **Available** tab

URL: `/agents/available`

<!-- TODO: Add screenshot — /images/agents/available.png -->

## What you see on each card

- **Name** and category badge (**Core**, **Governance**, or **Finance**)
- Short **description**
- **Skills included** — capabilities the agent unlocks
- **Works in** — related product areas (for example Resources Catalog, Analysis)
- **Based on** — typically *Latest cloud execution*
- **View details** — opens the detail dialog

If the list is empty, you will see: *No agents available at this time.*

## Install an agent

1. Click **View details** on an agent card
2. Review the description, skills, and metadata in the dialog
3. Click **Install Agent** (or **Cancel** to close without installing)
4. On success, Cloud2Gether shows **Agent installed successfully**
5. Switch to [Installed](../installed/) to confirm the agent appears there

{{< alert color="info" title="After install" >}}
Installed agents unlock capabilities in the areas listed under **Works in**. Make sure related modules (for example Resource Catalog or Lock-In Analyzer) are available on your plan and that cloud accounts are syncing.
{{< /alert >}}
