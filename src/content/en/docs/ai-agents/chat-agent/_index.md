The **Chat Agent** (C2G AI) is the conversational assistant embedded in the Cloud2Gether app layout. Use it to ask questions in natural language about your cloud environment and platform workflows.

Unlike marketplace agents under **Agents → Available / Installed**, Chat Agent is controlled by the application layout feature flag and may not appear in every environment.

## Prerequisites

- A Cloud2Gether organization with Chat Agent enabled for your environment
- Context improves when you have linked [cloud accounts](../../cloud-accounts/) and relevant Analysis modules in use

## How to access

1. Sign in to Cloud2Gether
2. Look for the C2G AI / chat entry point in the app layout (when enabled)
3. On the Dashboard profile card, you may also see a C2G AI control when the assistant is available

## What you can do

- Ask operational questions about your cloud posture and Cloud2Gether modules
- Get guided help while navigating Analysis tools
- Complement specialist agents (Resource, IaC, Lock-In) that power deeper automated skills
