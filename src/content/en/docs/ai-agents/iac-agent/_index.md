The **IaC Analysis Agent** (documented here as **IaC Agent**) evaluates infrastructure-as-code coverage and identifies gaps in automation and consistency. In the Agents marketplace it is categorized as **Governance**.

It works in **Resources** and **Analysis**, and is based on the **latest cloud execution**.

## Skills included

- IaC Coverage Analysis
- Drift Detection
- Best Practices Check
- Module Suggestions

## Prerequisites

- Linked [cloud accounts](../../cloud-accounts/)
- Access to [IaC Analyzer](../../solutions/iac-analyzer/) (sidebar: **Infrastructure**)

## How to install

1. Open **Agents → Available**
2. Find **IaC Analysis Agent**
3. Click **View details** → **Install Agent**
4. Confirm it appears under **Installed**
