The **Installed** tab shows agents already enabled for your organization. Use it to confirm what is active and to remove agents you no longer need.

## How to access

1. Open **Agents** in the left sidebar
2. Select the **Installed** tab

URL: `/agents/installed`

<!-- TODO: Add screenshot — /images/agents/installed.png -->

## What you see

Installed agents use the same card layout as Available (name, category, description, skills, works-in, based-on).

If nothing is installed yet, you will see: *No agents installed yet. Browse the Available tab to install agents.*

## Uninstall an agent

1. Open the **Installed** tab
2. Use the agent card action to uninstall the agent
3. On success, Cloud2Gether shows **Agent uninstalled successfully**
4. The agent returns to [Available](../available/) for reinstall if needed

{{< alert color="warning" title="Impact" >}}
Uninstalling an agent may disable the specialized skills that agent provided in related modules. Reinstall from Available when you need those capabilities again.
{{< /alert >}}
