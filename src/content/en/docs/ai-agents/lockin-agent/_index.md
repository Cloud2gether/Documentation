The **Lock-in Analysis Agent** (documented here as **Lock-In Agent**) analyzes infrastructure to detect vendor lock-in risks and evaluate portability across cloud providers. In the Agents marketplace it is categorized as **Governance**.

It works in **Resources** and **Analysis**, and is based on the **latest cloud execution**.

## Skills included

- Detect Proprietary Services
- Evaluate Portability Risk
- Estimate Migration Complexity
- Suggest Alternatives

## Prerequisites

- Linked [cloud accounts](../../cloud-accounts/)
- Access to [Lock-In Analyzer](../../solutions/lockin-analyzer/)

## How to install

1. Open **Agents → Available**
2. Find **Lock-in Analysis Agent**
3. Click **View details** → **Install Agent**
4. Confirm it appears under **Installed**

## How it helps

Use Lock-In Agent skills with Lock-In Analyzer **Analysis** and **Compare** views to understand proprietary service usage, portability risk, and migration complexity.
