The **Resource Agent** discovers and organizes cloud resources across providers, building a unified and searchable inventory. In the Agents marketplace it is categorized as **Core**.

It works in **Resources Catalog** and is based on the **latest cloud execution**.

## Skills included

- Resource Discovery
- Resource Classification
- Unified Search
- Tag Normalization

## Prerequisites

- Linked [cloud accounts](../../cloud-accounts/) with successful syncs
- Access to [Resource Catalog](../../solutions/resource-catalog/)

## How to install

1. Open **Agents → Available**
2. Find **Resource Agent**
3. Click **View details** → **Install Agent**
4. Confirm it appears under **Installed**

## How it helps

After install, Resource Agent skills support inventory quality in Resources Catalog — discovery, classification, search, and more consistent tagging across providers.
