**Expert Help** in the Organization App sidebar opens **Requests**, which maps to the **Service Hub** experience — create job requests, track their status, and browse experts to hire.

Page title on the hub: **Service Hub**

## Prerequisites

- An active Cloud2Gether organization
- Access to **Expert Help → Requests**

## How to access

1. Sign in to Cloud2Gether
2. In the left sidebar, expand **Expert Help** → **Requests**
3. Or open: <a href="https://app.cloud2gether.com/service-hub" target="_blank" rel="noopener noreferrer">https://app.cloud2gether.com/service-hub</a> (defaults to the Service Hub dashboard)

## Service Hub dashboard

From the hub you can:

| Card / area | Action |
|-------------|--------|
| **New Job Request** | Start a request at `/service-hub/job-request/create` |
| **Hire an expert** | Browse experts at `/service-hub/hire-an-experts` |
| **Your job requests** | Search and review existing requests (tabs below) |

### Job request status tabs

On **Your job requests**, filter by:

- **Requested**
- **In review**
- **Active**
- **Completed**

Search the list and open a request for details.
