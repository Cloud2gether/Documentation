**Hire an Expert** lets you find professionals for your needs — search the expert directory and browse available profiles.

## How to access

1. Open **Expert Help → Requests** (Service Hub)
2. Click the **Hire an expert** card  
   Or open: `/service-hub/hire-an-experts`
3. Use **Back to Service Hub** to return

<!-- TODO: Add screenshot — /images/expert-help/hire-an-expert.png -->

## What you can do

1. Enter a search term and click **Search**
2. Browse expert cards in the results grid
3. Use **Load more** when additional experts are available
4. If nothing matches, the empty state indicates no expert was found
