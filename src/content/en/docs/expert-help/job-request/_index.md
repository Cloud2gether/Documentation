**New Job Request** walks you through posting work for a Cloud Expert — from choosing the type of help to describing the need, selecting expertise, defining a budget, and confirming the post.

## How to access

1. Open **Expert Help → Requests** (Service Hub)
2. Click the **New Job Request** card  
   Or open: `/service-hub/job-request/create`
3. Use **Back to Service Hub** to return anytime

## Step-by-step

### 1. Choose the type of help

On **What type of help do you need?** select:

| Option | Description |
|--------|-------------|
| **Ask the Expert** | Get 1 hour of guidance or clarification from a Cloud Expert |
| **Custom Solution** | Request a Cloud Expert to build a solution or solve a technical issue |
| **War Room** | Coming soon — real-time help for critical incidents |

### 2. Describe your need

Provide the request details (name, technical issue, and context about your situation) as prompted by the form.

### 3. Select expertise

Choose the expertise tags/skills that match the help you need.

### 4. Define budget

Set the budget you want to pay **per hour** for the expert (minimum and maximum as shown in the UI).

### 5–6. Submit and confirmation

After processing, the **posted** confirmation summarizes your job (budget range, description, selected expertise) and shows what’s next.

## Track requests

Return to Service Hub to find the request under **Your job requests** (Requested / In review / Active / Completed). Open details to follow progress and related orders when available.
