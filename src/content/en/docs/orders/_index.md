**Orders** (sidebar: **Orders**) lists purchases and related transactions for your organization so you can review status, totals, and order detail.

Page title: **Your orders**  
Subtitle: *Review your previous orders and their status.*

## Prerequisites

- An active Cloud2Gether organization
- Access to the Orders menu item

## How to access

1. Sign in to Cloud2Gether
2. In the left sidebar, click **Orders**
3. Or open: <a href="https://auth.cloud2gether.com/auth/login/password" target="_blank" rel="noopener noreferrer">https://auth.cloud2gether.com/auth/login/password</a>

## Orders list

The table includes:

| Column | Description |
|--------|-------------|
| **Date** | When the order was created |
| **Transaction ID** | External transaction identifier |
| **Total** | Order total |
| **Status** | Current order status badge |
| **See details** | Opens the order detail page |

Use **Load more** when additional orders are available. Empty state: *No orders found*.

## Order detail

1. Click **See details** on a row
2. Review **Order Detail** (`/your-orders/<id>`):
   - **Status** (with optional **View or Print invoice** when shown)
   - **Date**
   - **Order total**
   - **Transaction ID**
   - **Order Summary** line items and **Grand Total**
3. Click **Back to Order list** to return
