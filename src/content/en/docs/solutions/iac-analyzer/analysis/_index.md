The **Analysis** route hosts the **IaC Hub**: KPIs, monitored accounts, and per-account detail.

## How to access

URL: `/iac-analyzer/analysis`

Open a specific account from the list (the app uses an `account` query parameter for drill-down).

<!-- TODO: Add screenshot — /images/iac-analyzer/analysis-list.png -->

## Account list

From the list you can:

- Review KPI summaries across accounts
- Start **New monitoring**
- Open an account to see detailed IaC findings

## Account detail

Inside an account:

1. Review coverage and findings for that account
2. Use re-run / analysis actions provided in the UI
3. Click **Back to Account list** when finished
