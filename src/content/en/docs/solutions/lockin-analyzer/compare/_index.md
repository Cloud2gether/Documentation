**Compare** lets you contrast Lock-In Analyzer results so you can see how risk and portability change across accounts or analysis points.

## How to access

1. Open **Analysis → Lock In Analyzer**
2. Select the **Compare** tab

URL: `/lock-in-analyzer/compare`

<!-- TODO: Add screenshot — /images/lockin-analyzer/compare.png -->

## Typical workflow

1. Ensure monitoring is enabled and at least one analysis has completed
2. Open **Compare** and select the items the UI offers for comparison
3. Review differences and return to [Analysis](../analysis/) for account-level detail
