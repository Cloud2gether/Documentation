**Graph** visualizes relationships between discovered cloud resources so you can navigate dependencies and related assets beyond a flat list.

## How to access

1. Open **Analysis → Resources catalog**
2. Select the **Graph** tab

URL: `/resources-catalog/graph`

<!-- TODO: Add screenshot — /images/resources-catalog/graph.png -->

## When to use Graph

- Explore how resources connect across services or accounts
- Investigate blast radius or dependency clusters
- Complement the tabular **Resources** inventory with a visual map

{{< alert color="info" title="Data dependent" >}}
The graph reflects resources already synced into the catalog. If the canvas is empty, confirm [Sync executions](../executions/) completed successfully.
{{< /alert >}}
